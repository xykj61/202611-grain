## 2. Five Commitments of the Open Door

1. **Welcome Fresh Eyes Warmly:** Build every explanation from first principles
   in natural sequence so newcomers feel right at home and experienced builders
   enjoy the clean flow.
2. **One Move per Step, Concrete First:** Run the command or open the working
   file first, then introduce its name once in everyday speech.
3. **Encouraging Exactness:** Guide each step plainly and kindly (`run this
   command to watch the GREEN witness line light up`), letting real results
   build genuine confidence.
4. **Root Technical Bounds in Living Purpose:** Connect engineering choices to
   the world they nourish -- biocyclic vegan soil, shaded neighborhood canopies,
   repairable boards for family workshops, sovereign `Kumara` keys, and
   household `Glasswall` peace -- stated once where the insight lands best.
5. **Shared Reproducibility:** Pair every number with the exact command that
   produces it so every student can verify the craft firsthand.
