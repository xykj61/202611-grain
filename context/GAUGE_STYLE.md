## The Core Discipline

A carpenter's **marking gauge** scores one crisp, true line in wood before the saw touches it. **Gauge Style** brings that exact clarity to technical prose:

1. **Lead With What Stands Today:** Open every page by naming what actually compiles, runs, and passes witnesses *right now*. Put planned horizons in their own clearly labeled section (`Room: vision` or *Next Horizons*) so aspiration never masquerades as shipped code.
2. **Prefer Executable Commands Over Hand-Typed Counts:** Hand-typed file and module counts go stale on the next commit. Either generate front-door metrics automatically (`README.md`) or show the one-line command a reader can run to measure the live tree.
3. **Name Both Sides of Every Seam:** State what a module guarantees *and* what lies outside its custody (for example, distinguishing integrity verification from seller identity authority).

## Three Settings of Ceremony

Match header weight to the distance of the reader:

- **Door (`README.md`, room `README.md`, `SOURCE.md`):** Welcoming front threshold -- carries `Language`, `Stamp`, `Voice`, `Style`, and `Status` (`Room: checkable | vision | mixed`), followed immediately by plain-English purpose and runnable commands.
- **Field (`active-tablecloth/`, `blazepod/`, architecture specs):** Working blueprints -- crisp ASCII block diagrams, bounded memory tables, and numbered orbits.
- **Bench (`session-logs/`, `mitra-shed/SHRED_PREP.md`, `.kyri` receipts):** Compact operational records -- zero filler, exact commit nibs, exact witness verdicts.
