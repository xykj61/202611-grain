# Guide -- Clean Processing and Craft Mill

**Stage:** Bloom Practice Layer
**Voice:** Teacher & Civic

---

## 1. Small-Batch Honest Processing

When oat groats, sunflower seeds, herbs, or linen flax leave the field, clean
local processing keeps value inside the growing community. Every batch is milled
or pressed using repairable stainless mechanical equipment with documented
bearings, belts, and open schematics.

## 2. Vessel Seals with Amphora

Each finished crate or jar lot receives a deterministic **Amphora** vessel seal:

- **Input lot:** linked by `Blaze` content hash to the exact harvest bed(s),
- **Process parameters:** date stamp (`YYYYMMDD.HHMMSS`), mill temperature,
  and moisture reading,
- **Custody proof:** Ed25519 signature from the mill steward's `Kumara` key.

Any neighbor or co-op member scanning the crate verifies its provenance offline
without pinging a corporate cloud database.
