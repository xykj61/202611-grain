## Why One `yonder/` at the Bottom of the Tree

In plain daily work, *archive* and *yonder* express one human wish: **"Keep this safe so I can open it later if I ever want it, and keep it out of my face while I build today."**

Naming this single root vault **`yonder/`** gives three practical gifts at once:

1. **Alphabetical calm:** Starting with `y`, `yonder/` sorts naturally to the very bottom of every directory listing and file tree, keeping living code, docs, and active boards at eye level.
2. **Zero scattered cold drawers:** Every former `**/archive/` and `**/yonder/` subdirectory across the repository now rests here under its origin subfolder (`yonder/<origin>/`), eliminating twenty separate cold closets.
3. **Fast, focused Gemini context:** `.gitignore` admits `!/yonder/` so Git preserves every byte with full cryptographic history, while [`.geminiignore`](../.geminiignore) skips `yonder/` during routine searches unless you explicitly open a path inside `yonder/`.
