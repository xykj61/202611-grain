# Air -- Stamp-and-Name, Evergrow, & The Comlink Tendency

**Element & Goal:** Air / Fun (*"Where does each thing end?"*)
**Stamp:** `20261115.125000`

## 1. Stamp and Name -- Count, Never Number

1. **Mark by stamp and plain name:** A one-clock chronological stamp
   (`TZ=America/New_York`, `YYYYMMDD.HHMMSS` in code/manifests and
   `YYYYMMDD-HHMMSS_sprig.ext` on dated shelves) orders work; a plain
   descriptive sprig names what it is.
2. **Ban ascending serial numbers in living names & headers:** Never mint
   forecast or sequence numbers (`01-`, `_100_`, `Orbit 14`, `lap2`, `v3`,
   `WAYMARK[0-9]+`) into living filenames, symbol names, or standing file
   headers. Derive totals by measurement (`git rev-list --count HEAD`, `wc -l`).
   (`construction/REDS.md` `%NNN` rows are the sole historical census
   exemption.)
3. **Illustrate with placeholders:** Write example shapes as
   `date/YYYYMMDD/YYYYMMDD-HHMMSS_sprig.ext`, never fabricated digit stamps.
4. **Dated testimony stays untouched:** Any file whose basename carries a
   `YYYYMMDD-HHMMSS` stamp keeps the exact words it wrote unless Keaton directs
   a rename; living files repoint and sweep forward on touch.

## 2. Chronological Pins & Evergrow (*Spec-ulation*)

- **Zero semantic versioning (`1.x.x` banned):** Every `.rye`, `.glow`, `.brix`,
  and `grain-ww` parcel uses monotonic `YYYYMMDD.HHMMSS` stamps.
- **Evergrow contract:** Newer stamps within an immutable epoch name (such as
  `202611-comlink-gemini`) must **offer more and require less** (drop zero
  exports, add zero capability or memory demands). Breakage requires a new name.

## 3. The Comlink Tendency & Alias Sameness

- Choose warm, plain craft and agricultural words (`sheaf`, `trellis`, `assay`,
  `pith`, `mill`, `pond`, `vantage`, `sundial`) over cryptic 4-letter acronyms.
- Use **`Resonance`** everywhere for the audio studio (never retired `Lotus`).
