## How `bloom/` and `docs-geode/` Work Together

Grain serves two kinds of readers with equal respect by giving each their own tailored doorway:

- **[`../../../docs-geode/`](../../../docs-geode/README.md) (The Operator & Systems Reference Geode):** Built for seasoned developers, systems engineers, and pier operators who already speak terminals, compilers, and cryptographic digests and want fast, crystal-verified reference pages.
- **`modules/apps/bloom/` (The Wing-Beside-You Learning Garden):** Built for **complete beginners, students, artists, and curious minds of any age** sitting at a macOS computer with **zero prior coding prerequisites** -- using our **Wing-Beside-You (Guardian Dragon)** teaching approach: warm, protective, unhurried, explaining every key on a macOS keyboard (`Command`, `Option`, `Return`) and celebrating every small working creation.
